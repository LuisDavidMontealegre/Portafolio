MuebleArte

Plataforma e-commerce para la venta de muebles artesanales de alta calidad

Java (Spring Boot) MySQL HTML5/CSS3/Bootstrap JavaScript (ES6) Scrum / Jira GitHub / Git

📌 Contexto del proyecto

Problemática: La mueblería MuebleArte perdía ingresos debido a obras en la vía pública que afectaban la visibilidad de su tienda física. La solución fue migrar su logística y presencia al canal digital.

Público objetivo: Adultos de 20 años en adelante, residentes en CDMX, que buscan amueblar su primer hogar o renovar sus espacios.

Misión: Transformar espacios en hogares mediante muebles de alta calidad, combinando maestría artesanal con diseño contemporáneo.

Visión: Ser la marca referente en el mercado, uniendo generaciones a través del diseño.

Modelo de negocio: D2C (Directo al Consumidor) multicanal, sin intermediarios, integrando e-commerce, redes sociales y punto físico.

🔧 Mi rol y responsabilidades

  • Análisis y diseño de la base de datos relacional (MySQL).
  • Desarrollo del backend en Java con Spring Boot (API REST, lógica de negocio).
  • Implementación del carrito de compras, pasarela de pago simulado y gestión de pedidos.
  • Coordinación del equipo como Scrum Master en un sprint, utilizando Jira para el seguimiento de tareas.
  • Gestión del repositorio en GitHub (control de versiones, ramas, pull requests).
  • Colaboración en el frontend (HTML, CSS, JavaScript) para componentes dinámicos.

🎯 Funcionalidades implementadas

  • Registro y autenticación de usuarios (login seguro)
  • Catálogo de productos con filtros y búsqueda
  • Carrito de compras y proceso de checkout (pasarela de pago simulada)
  • Historial de pedidos y perfil de usuario
  • Formulario de contacto y retroalimentación
  • Preguntas frecuentes (FAQ)
  • Diseño responsivo (mobile-first) y compatible con navegadores modernos
✅ Resultado: Se logró una plataforma funcional que reemplazó procesos manuales, aumentando la productividad y el control del negocio. Lista para desplegar en la nube.
