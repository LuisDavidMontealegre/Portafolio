MBM Sports

Plataforma e-commerce para la venta de artículos deportivos – Hackathon 5 días

HTML5/CSS3/Bootstrap JavaScript (ES6) + LocalStorage Responsive Design Git / GitHub Scrum / Jira

📌 Landing page del hackathon

Reto: Desarrollar una tienda en línea completamente funcional (front-end) en 6 horas, con carrito de compras, pasarela de pago simulada, gestión de pedidos y experiencia de usuario fluida.

Equipo: 4 desarrolladores.

Público objetivo: Jóvenes deportistas y entusiastas del fitness entre 18 y 35 años, buscando equipo deportivo de calidad.

Solución: Creamos MBM Sports, una tienda que permite navegar productos, agregar al carrito, vaciar carrito, eliminar ítems individuales, completar datos de envío y realizar un pago simulado con alerta de éxito.

Valor diferencial: Interfaz amigable, carrito persistente en localStorage, manejo de imágenes con tamaños responsivos y validaciones en todos los pasos.

🔧 Mi rol y responsabilidades

  • Diseño e implementación del front-end completo (HTML, CSS, Bootstrap).
  • Desarrollo del carrito de compras con JavaScript puro y localStorage.
  • Creación de la página de checkout, resumen de pedido y formulario de cliente.
  • Implementación de la pasarela de pago simulada y validación de datos.
  • Coordinación del equipo y aplicación de Scrum.
  • Gestión del repositorio en GitHub (ramas, pull requests, code review).
  • Maquetación responsiva y compatibilidad cross-browser.

⚙️ Stack tecnológico

HTML5 / CSS3 / Bootstrap 5
JavaScript
LocalStorage

Diseño responsivo

🎯 Funcionalidades implementadas

  • Catálogo de productos con imágenes y precios dinámicos.
  • Carrito de compras persistente (localStorage).
  • Agregar y eliminar productos individualmente.
  • Vaciar carrito completo con confirmación.
  • Resumen del pedido con total y miniaturas.
  • Formulario de datos de envío (nombre, email, dirección).
  • Página de pago simulado con validación de tarjeta.
  • Mensaje de éxito y limpieza del carrito.
✅ Resultado del hackathon: Logramos una plataforma completa y funcional en el tiempo establecido. El proyecto fue presentado con éxito y recibió retroalimentación positiva por su usabilidad, código limpio y diseño responsivo.
